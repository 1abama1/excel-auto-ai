# Миграция PaddleOCR — результат 19 октября 2026

## Готовый запуск

`Launch.cmd` запускает `dist-paddle/DocumentExcel/DocumentExcel.cmd`. Переносите всю папку DocumentExcel: она содержит собственный Python 3.12.13, Qt, PaddleOCR 3.7.0, PaddlePaddle CPU 3.3.1, PaddleX 3.7.2 и проверенные модели PP-OCRv5. Интернет при работе не нужен. На целевом Windows x64 требуется Microsoft Visual C++ Redistributable 2015–2022 x64. Старые сборки сохранены.

Размер runtime с моделями — около 1,3 ГБ. Исходники пакета сверены с проектом; SHA-256 Python-файлов — в `build.json`, фактические зависимости — в `requirements-locked.txt`, модели/URL/контрольные суммы — в `models/paddle/manifest.json`. Обновлённый `uv.lock` успешно прошёл `uv lock --check --offline`: 123 пакета.

## Ограничения

* Номер цифрового screenshot не получен надёжно обоими движками. У Paddle значение осталось неразрешённым, без автоматического подтверждения.
* Сырая проба Ү/Ө/Ң содержит смешение похожих кодов и ошибку регистра, хотя буквы присутствуют в словаре модели. Контекстная нормализация одинаковых glyph-кодов применяется только к явно кириллическим полям; неоднозначные символы не угадываются. Безошибочное чтение кыргызских имён не заявляется.
* **3/4 против 0/4 относятся только к этим фикстурам.** Превосходство на реальных удостоверениях пользователя не подтверждено: новый размеченный разрешённый набор не предоставлен.
* GPU, RapidOCR/ONNX, чистая Windows 11, подписанный EXE/MSI и нативное открытие нового XLSX в Microsoft Excel не проверялись. Поставка — переносимый Python runtime с CMD-запуском; CPU проверен.
* Аппаратная камера в этой миграции повторно не снималась. Интерфейс, кадры и освобождение устройства проверены автоматическими тестами.

Архитектура, установка, модели, MRZ и повторение benchmark: [PADDLE_MIGRATION.md](PADDLE_MIGRATION.md). Tesseract сохранён как явно выбираемый резервный движок. Исходные фотографии, ручные правки, адрес и Excel mappings работают в прежнем workflow.
