# Один EXE: установка и запуск

Готовый файл: `dist-onefile/DocumentExcel.exe`, Windows 10/11 **x64**.
На другой компьютер достаточно перенести только этот EXE. Системный Python,
uv, pip, NVIDIA, CUDA и ручные команды не нужны.

При первом запуске появляется окно подготовки. Программа:

1. Проверяет и распаковывает включённые Python 3.12, интерфейс, основной
   RapidOCR CPU, локальные ONNX-модели, нативные модели PaddleOCR,
   зависимости и шаблон договора.
2. Автоматически скачивает PaddleOCR 3.7.0, PaddlePaddle **CPU** 3.3.1,
   PaddleX 3.7.2 из PyPI. Конкретные Windows/Python wheels и SHA256 закреплены
   в `uv.lock`, произвольного обновления зависимостей нет.
3. Проверяет включённые три официальные модели PP-OCRv5: mobile detection,
   Cyrillic recognition, English recognition. Каждый файл весов и конфигурации
   проверяется по заранее зафиксированному SHA256. Если файлы повреждены,
   установщик восстанавливает их из официального источника.
4. Проверяет CPU-библиотеки и открывает приложение.

Для первого запуска нужен интернет: около **102 MiB** пакетов PaddleOCR CPU
сверх EXE. На медленном соединении подготовка занимает несколько минут;
в окне показаны компонент и число скачанных мегабайт. После установки
программа работает **без интернета**, повторного скачивания нет.
После обрыва повторно откройте тот же EXE: полностью скачанные проверенные
компоненты используются из кеша. Частично скачанный файл загружается заново.

EXE занимает примерно **350 MiB**. Рекомендуется не менее **2,5 ГБ** свободного
места для установленного приложения и кеша. Компоненты устанавливаются один
раз в `%LOCALAPPDATA%\DXOCR\<версия>`, настройки — в
`%LOCALAPPDATA%\DocumentExcel`. Системные Python и пакеты не изменяются;
администраторские права не запрашиваются. Общие Microsoft DLL поставляются
локально из лицензированного Qt runtime.

Если на системном диске мало места, EXE автоматически выбирает доступный
локальный диск с достаточным свободным местом: `D:\DXOCR\user-...\<версия>`
(буква зависит от компьютера). Следующие запуски используют ту же установку.
Настройки остаются в профиле пользователя.
Временные файлы установки и обработки размещаются на выбранном диске.

Русское имя пользователя поддерживается: для нативного Paddle используется
короткое ASCII-имя каталога моделей. Если короткие имена Windows отключены,
проверенные веса копируются в `%PUBLIC%\Documents\DocumentExcel\ocr-models`.
Этот кеш содержит только публичные модели, без фотографий и реквизитов.

Основной OCR остаётся RapidOCR CPU по результатам benchmark. PaddleOCR CPU
доступен в настройках. Оба полностью устанавливаются этим EXE. Загрузка
фотографий **не запускает распознавание**: сначала добавьте FRONT/BACK,
затем нажмите «Распознать документы».

Храните EXE в удобном месте и открывайте его для запуска приложения.
Внутренние папки не требуется копировать вместе с ним. Подготовка компонентов
не отправляет фотографии или реквизиты: скачиваются только публичные пакеты
и модели. Ошибка сети или контрольной суммы останавливает подготовку и
показывает сообщение; непроверенный wheel не выполняется.

Шаблон Лермонтова включён. На чистом профиле он выбран автоматически;
существующий пользовательский шаблон сохраняется, пока доступен его файл.
Лицензии, источники приложения и документация распаковываются вместе с runtime.
Файл не подписан сертификатом издателя. Чистая Windows 11/VM отдельно не
проверялась; фактические проверки Windows 10 перечислены в TEST_REPORT.md.

## Воспроизводимая сборка

Из проверенного локального runtime:

```powershell
dist-digital/DocumentExcel/runtime/python.exe scripts/build_onefile.py
```

Вход — `dist-digital/DocumentExcel`; исходники bootstrap — `installer/`.
Выход — один `dist-onefile/DocumentExcel.exe` и необязательный технический
`DocumentExcel.build.json` с хешем. ZIP включён в EXE, отдельные файлы для
распространения не нужны. После изменения только C# launcher допускается
`--repack-launcher`; изменение Python provisioner требует пересборки core.

Для изолированной QA предусмотрены `--install-dir`, `--data-dir`,
`--prepare-only`, `--offline`, `--quiet`, а после `--` передаются параметры
самому приложению. Эти аргументы обычному пользователю не нужны.
