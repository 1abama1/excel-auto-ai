# Документ → Excel

Простая локальная программа для Windows: выберите готовый XLSX, добавьте фотографию паспорта, проверьте найденные сведения и сохраните изменения в выбранный договор.

## Обычный сценарий

1. **Загрузка.** Выберите Excel-договор и добавьте одну или две фотографии. Можно перетащить файл и несколько снимков, загрузить отдельную сторону или сделать фото веб-камерой.
2. **Проверка.** Нажмите «Распознать паспорт». Исправьте только нужные значения прямо в форме. Не найденные поля можно оставить пустыми. Есть переход без распознавания.
3. **Готово.** Нажмите «Сохранить договор». В одной сводке проверьте изменения и при необходимости выберите общее действие с прежними персональными сведениями. Изменения записываются в тот XLSX, который вы выбрали; доступны файл, папка и новый документ.

Отсутствие ПИН, ФИО, регистрации, даты или второй фотографии **не блокирует сохранение**. Если новых данных нет, можно сохранить выбранный файл без обновления паспортных полей. Программа явно показывает пропуски.

## Старые данные и сохранность Excel

Если обнаружена смена клиента, прежние паспортные реквизиты заменяются, а отсутствующие новые сведения и фотографии очищаются в разрешённых областях после общей итоговой проверки. Если принадлежность прежних значений неизвестна, выберите одно действие: сохранить их для того же клиента или очистить для нового.

Программа изменяет только проверенные ячейки клиента. Инструменты, цены, залог, адрес объекта, оформление и посторонние рисунки сохраняются. Формулы не заменяются; небезопасные формулы с прежними персональными данными требуют исправить карту. Выбранный файл заменяется только после записи временного результата, повторного открытия и проверки. Тот же файл переименовывается в `ФИО DD.MM.YYYY.xlsx` с текущей локальной датой; папка не меняется, дополнительный XLSX не создаётся. При совпадении имени с другим файлом добавляется номер. Если ФИО отсутствует, используется `Договор DD.MM.YYYY.xlsx`. Если запись или проверка не удалась, выбранный документ сохраняет прежнее содержимое. Закройте его в Excel перед сохранением.

Проверенная структура договора распознаётся автоматически. Неизвестный XLSX требует однократной настройки через «Дополнительно → Расположение полей». Имя файла само по себе не подтверждает совместимость.

## Запуск Windows x64 CPU

Дополнительная поставка одним EXE: **`dist-onefile/DocumentExcel-current.exe`**.
Для переноса достаточно этого файла. При первом запуске нужен интернет для
автоматической установки Paddle CPU; затем приложение работает локально.
Подробнее: [один EXE](docs/ONEFILE_WINDOWS.md).

Готовая автономная папка: `dist-renamed/DocumentExcel`.
Запустите **DocumentExcel.cmd**. Для переноса скопируйте всю папку.
`Launch.cmd` использует поставку, указанную в `current-build.txt`.

Включены Python 3.12, Qt, RapidOCR, PaddleOCR и локальные модели. Основной движок RapidOCR CPU сохранён по [ранее измеренным результатам](docs/CPU_BENCHMARK.md). NVIDIA, CUDA и интернет для обычной работы не нужны. Реальные документы и фото в поставку не входят.

## Приватность

OCR выполняется локально. Облачные API не используются. Паспортные данные не записываются в обычные логи и историю. Камерные временные файлы удаляются при очистке/закрытии приложения; пользовательские оригиналы не удаляются. Готовые договоры и явно сохранённые копии фото остаются в выбранных папках. Авария ОС может оставить временные файлы; гарантированного стирания SSD нет.

## Разработка и проверки

```powershell
.venv\Scripts\python.exe -m pytest
.venv\Scripts\ruff.exe check src tests scripts
.venv\Scripts\mypy.exe src/document_excel/domain src/document_excel/infrastructure src/document_excel/application
```

Python ≥3.12, PySide6, OpenCV, Pillow, Pydantic v2, openpyxl; зависимости — `pyproject.toml` и `uv.lock`. Запись выполняется точечным изменением исходного ZIP/XLSX с повторным открытием и проверкой результата. Основной режим — `BEST_EFFORT_UPDATE`; генерация шаблонов и прежний строгий сервисный режим сохранены для явного дополнительного использования.
