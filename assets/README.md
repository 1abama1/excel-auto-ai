# Локальные шаблоны

Пользовательский договор `lermontov.xlsx` хранится локально и исключён из Git.
Фотографии, заполненные договоры и результаты распознавания также не входят
в репозиторий.

Для работы с собственным договором выберите его в интерфейсе приложения.
Для локальных проверок предоставленного шаблона и сборки EXE поместите его
копию в `assets/lermontov.xlsx`. Существующий локальный файл не изменяется.
Проверки, которым нужен этот документ, пропускаются, если он отсутствует.

В репозитории есть отдельный безопасный демонстрационный шаблон:
`src/document_excel/resources/templates/DEMO-not-a-contract.xlsx`.
Он предназначен для тестов и не является настоящим договором.
